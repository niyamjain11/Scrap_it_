## Reporting a Vulnerability

We take the security and integrity of user information, pricing data, and compliance records seriously.

If you believe you have discovered a security vulnerability in this project, please follow these steps:

1. **Do not create a public GitHub issue.**
2. Send an email to **niyamj1102@gmail.com** with the subject line:  
   `[SECURITY VULNERABILITY] - <Short Description>`.
3. Include the following details to help us investigate:
   * Description of the potential vulnerability
   * Steps to reproduce or proof-of-concept
   * Potential impact on users, data privacy, or backend services
   * Recommended remediation (if known)

### Response Timeline
* **Acknowledgment:** Within 48 hours
* **Assessment & Fix Target:** Within 7 days
* **Public Disclosure:** Coordinated after a fix is verified and deployed

Thank you for responsibly disclosing vulnerabilities to keep the platform secure for everyone.
